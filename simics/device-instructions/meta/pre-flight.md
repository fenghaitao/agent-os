# Pre-flight Check for Simics Device Operations

## Environment Validation
- Verify Simics installation and version compatibility
- Check device development environment setup
- Validate agent-os configuration for Simics integration
- Confirm access to platform product documentation

## Project Structure Check
- Ensure .agent-os directory structure exists
- Verify device standards and templates are available
- Check platform product context if specified
- Validate user permissions for file operations

## Dependency Verification
- Confirm required Simics modules are available
- Check development tool dependencies
- Verify platform integration requirements
- Validate testing framework prerequisites
