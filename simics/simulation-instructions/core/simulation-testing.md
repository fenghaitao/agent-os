# Simulation Testing Framework Rules

## Overview
Create and execute simulation testing environments for Simics platforms and devices.

<process_flow>

<step number="1" name="test_environment_setup">
### Step 1: Test Environment Setup
- Configure simulation environment
- Setup test data and scenarios
- Initialize testing framework
- Validate test environment readiness

</step>

<step number="2" name="device_testing">
### Step 2: Device Testing
- Execute device unit tests
- Test register operations
- Validate interrupt handling
- Check state management

</step>

<step number="3" name="platform_testing">
### Step 3: Platform Testing
- Test device integration
- Validate system scenarios
- Check performance metrics
- Test error conditions

</step>

<step number="4" name="automated_testing">
### Step 4: Automated Testing
- Setup continuous testing
- Create regression test suite
- Implement test automation
- Generate test reports

</step>

<step number="5" name="test_validation">
### Step 5: Test Validation
- Analyze test results
- Identify and fix issues
- Update test documentation
- Provide testing recommendations

</step>

</process_flow>
