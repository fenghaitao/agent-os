# Pre-flight Check for Simics Platform Operations

## Platform Environment Validation
- Verify platform product documentation exists
- Check platform development environment setup
- Validate agent-os configuration for platform integration
- Confirm access to device specifications

## Platform Requirements Check
- Ensure platform product mission is defined
- Verify technical stack documentation exists
- Check device portfolio specifications
- Validate roadmap and phase definitions

## Integration Readiness
- Confirm device specifications are available
- Check platform assembly requirements
- Verify integration testing framework
- Validate configuration management setup
